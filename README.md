# house-price-predictor-random-forest
Predicts house prices using a Random Forest model (Kaggle Intro to ML)

# Competition Description
link: https://www.kaggle.com/competitions/home-data-for-ml-course

Ask a home buyer to describe their dream house, and they probably won't begin with the height of the basement ceiling or the proximity to an east-west railroad. But this playground competition's dataset proves that much more influences price negotiations than the number of bedrooms or a white-picket fence.
With 79 explanatory variables describing (almost) every aspect of residential homes in Ames, Iowa, this competition challenges you to predict the final price of each home.

# Steps

2-read data by pandas
3-Set X(the column on the basis of which I have to predict)
4- split data using train_test_split
5-set mode RandomForestRegressor
6-fit the data
7-made predictions

# How to run
This notebook was built on Kaggle. The data is not included here because of Kaggle's data-sharing rules.
1-Download `train.csv` and `test.csv` from the competition page above and put them in a `data/` folder.
2-Change the file paths in the notebook to `data/train.csv` and `data/test.csv`.
3-Run the notebook, or open it directly on Kaggle where the data is already available.
